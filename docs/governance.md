# ガバナンス（役割・権限・データの境界）

## 役割

- 基盤の担当（プラットフォームリード）: manatago
- Admin 権限: manatago と新谷の2人のみ
- 将来の追加メンバー: 通常ユーザー（Admin ではない）。日常の作業上の立場は新谷と同じ
- 新谷の Admin は権限として持つだけで、日常作業は通常ユーザーと同じ立場で行う

## データの境界

- 共有 DB に入れるのは共有情報のみ。個人データは入れない（個人側は ProjectTitan）
- 身元情報（連絡先など）は、仕事で使うものをすべて共有 DB に列挙する。仕事で使う個人のアドレスも含む
- 共有文書は当面、無期限で保持する

## 個人側との行き来

- 個人タスクが共有タスクになったら「昇格」させる。コピーを共有 DB に作って正本をそちらへ移し、個人側にはリンクだけ残す
- 相手側の基盤で進める仕事（参加型の仕事）は、相手側が正本。ここには持ち込まず、個人側でも通知・リマインドどまりにする

## インフラ

- 共有 VPS は manatago の所有。設定・構築作業は新谷側が担う
- ネットワークは2つのテールネットに分ける（manatago 側と新谷側）。境界をまたぐのは VPS のデバイス共有のみ
- Git LFS の公開エンドポイント（平文 HTTP）は、テールネット内へ移行して閉じる（手順は別途）
