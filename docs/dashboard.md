# ダッシュボード（人間用）

- 共有タスクの一覧画面。アプリの `/` で表示する（https://xvps.tail90c25f.ts.net/ 、テールネット内のみ）。
- **v1 は読み取り専用**。タスクの登録・変更はエージェント（MCP）経由で行う（docs/mcp-tools.md の「v1 に入れないもの」参照）。
- 表示はサービス層（app/services.py）経由。ダッシュボード内部では読み取り専用スコープ（tasks:read / identities:read / documents:read）の合成エージェントとしてサービス層を呼ぶ。書き込みスコープは持たない。
- 一覧は「未完了」「完了」の2タブに分ける（2026-11-10 決定）。各タスクはどちらか一方のタブにだけ表示する。未完了タブの並び順は「期限切れ → 48時間以内に期限 → 進行中 → その他（期限順）」、完了タブは完了した順（新しい順）。長期タスクも含め未完了は常に全件見える。優先度は並び順と一覧内の強調（期限切れの赤字、期限の相対表記）で示す。要約セクションのような二重表示は作らない。
- 絞り込みは status / owner / project のクエリパラメータと、完了・アーカイブを隠す指定。
- 見た目は試作モック（docs/shared-tasks.html）のデザインに合わせる（ダークヘッダー、件数カード、状態の色分けバッジ、台帳番号チップ、期限の相対表記）。モックの追加フォーム・操作ボタン・localStorage の仕組みは、読み取り専用という v1 の方針のため持ち込まない。台帳番号は登録順（created_at 順）で固定し、絞り込みでは変わらない。
